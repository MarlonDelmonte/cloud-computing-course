This activity is my first time learning more about cloud computing and using GitHub for a course project.
At first, I thought cloud computing was only about saving files online, but
I learned that it is also used in many apps and services that I use every day.

Three cloud services that I often use are Google Drive, Canva, and Messenger.
Google Drive is a SaaS because I can use it online to save and access my
files without managing the system. I consider it a Public Cloud because
many people can use it through the internet. Canva is also SaaS because
I can use its design tools online. It is also a Public Cloud because it is
available to many users. Messenger is another SaaS because I use it online
to communicate with other people. It can also be considered a Public Cloud
because many users can access it.

I also learned about Git and GitHub for the first time in this activity.
I learned that Git helps keep track of changes in a project. GitHub can
be used to store projects online and make it easier for people to work
together. It can also help prevent mistakes because we can see the
changes made to our files.

Overall, this activity helped me understand the basic idea of cloud
computing and version control. Since this is my first time using GitHub
for a course activity, I learned how to create a repository, organize
files, and use a README file. I think these skills will be useful for
my future school projects.
